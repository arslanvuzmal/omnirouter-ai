# Code of conduct

## Standard

Be civil and constructive. Assume good faith. Critique the work, not the person.

Unacceptable: harassment, personal attacks, discriminatory language, or publishing others private information.

## Scope

Applies to issues, pull requests and any other project space.

## Enforcement

Report concerns via a GitHub issue. The project owner may remove comments, close threads, or block accounts that breach this standard.

## Attribution

Adapted in spirit from the Contributor Covenant, written for a single-maintainer portfolio project.
